# AImove PosePilot

A platform for BVH visualisation and analysis.

## About

PosePilot is a web-based tool developed by AImove for visualising and analysing BVH (Biovision Hierarchy) motion capture files. The platform provides interactive 3D visualisation, scene management, and analysis tools for motion data.

## Features

- Interactive 3D BVH visualisation
- Scene management and customisation
- Motion analysis tools
- Web-based, no installation required

## Usage

Visit the live site: [https://aimove-posepilot.github.io/](https://aimove-posepilot.github.io/)

## Technology

Built with modern web technologies for fast, browser-based motion capture visualisation.
